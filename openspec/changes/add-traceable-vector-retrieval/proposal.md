## Why

CampusClaw 迭代 1 已具备登录、角色授权、班级隔离和教学材料入库，但用户只能按标题浏览材料，无法用自然语言定位正文中的具体依据。教师和学生需要在不突破班级边界的前提下检索本班知识库，并能从每条结果追溯到原材料及对应切片，避免无法验证来源的回答。

## What Changes

- 将已入库正文切分为带序号和字符区间的知识切片，正文保存在 MySQL。
- 使用 Qdrant 保存切片向量与最小关联标识；向量主键与 MySQL 切片主键一致，Qdrant 不重复保存正文。
- 提供 `keyword`、`vector`、`hybrid` 三种检索模式，默认使用混合检索。
- 所有检索路径仅从服务端 Session 获取 `class_id`；客户端携带的班级字段一律忽略。
- 每条命中返回材料标题、材料标识、切片标识、切片序号、字符区间、摘录以及可解释的排序信息。
- 无有效候选时返回「资料中未找到相关内容」，不得用低相关结果凑数。
- 提供有出处的简短问答：只有检索到本班切片后才调用生成模型，回答中的 `[1]`、`[2]` 与引用列表顺序一致。
- 教师可选择自动窗口、自定义分隔符或 Markdown 标题层级切分，并可按新策略重建已有材料索引。
- Docker Compose 增加仅内部可达的 Qdrant 服务；嵌入与生成模型密钥只存在于服务端环境变量。

## Capabilities

### New Capabilities

- `knowledge-retrieval`: 班级范围内的切片入库、关键字/向量/混合检索、出处追溯、无依据处理与引用式回答。

## Impact

- 数据库新增 `knowledge_chunks`，并为关键字检索建立适合中文的全文索引。
- Compose 新增 Qdrant 及持久化卷，不向宿主机映射 Qdrant 端口。
- 上传流程在原文入库后增加切分、嵌入与向量写入；失败不删除已保存的原材料。
- API 新增 `/api/search`、`/api/ask`、材料重建索引及教师查看向量关联信息的接口。
- 前端新增检索页、引用式问答页和教师切分策略控件。
- 本变更依赖 `add-auth-rbac-class-knowledge` 已提供的会话、角色、班级隔离、材料和知识库正文。

## Non-goals

- 不实现跨班级、跨学校或全局知识库检索。
- 不实现流式长对话、Agent 工具调用或多轮自主规划。
- 不实现交叉编码器重排序、模型微调或自动评测平台。
- 不将正文复制到 Qdrant，也不允许浏览器直接访问 Qdrant 或模型网关。
- 不允许无检索依据时调用模型自由回答。
- 不实现多副本检索服务、分布式任务队列或生产级高可用。
