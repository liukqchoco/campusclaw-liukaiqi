# 设计：个人 AI 应用平台阶段性验收

## 1. 总体链路

```text
浏览器
  → 选择 AI 应用并发送消息
  → Go API 校验用户、班级、应用和会话
  → 渲染提示词模板
  → 在应用绑定且启用的 Skill 中确定性路由
  → 在应用绑定的本班材料中检索 Top-K 切片
  → 组装 LLM messages 与最小工具候选集
  → LLM 决定是否调用工具
  → 宿主校验并调用 MCP Server
  → 工具结果以 tool message 回传 LLM
  → SSE 流式返回最终回答
  → 保存脱敏验收轨迹
```

## 2. AI 应用与提示词模板

- `prompt_templates` 保存班级级模板，支持 `{{class_name}}`、`{{user_name}}` 和 `{{app_name}}` 三个变量。
- `ai_apps` 绑定一个模板；材料和 Skill 使用关联表绑定，不复制正文。
- 每次消息都读取最新模板与绑定，教师修改后从下一次消息开始生效。
- 模板渲染结果放入系统消息；原始模板、渲染结果和变量写入脱敏轨迹。

## 3. 知识库上下文

- 检索范围是“当前用户班级 ∩ 当前应用绑定材料”。
- 切片正文与可追溯区间保存在 MySQL，课程 `course-embedding` 模型生成的 2048 维向量及最小关联标识保存在内部 Qdrant。
- 查询时分别产生确定性关键字排名与 Qdrant 余弦排名，先过滤低于 0.35 的向量候选，再以 `k=60` 的 RRF 融合，最多保留 4 个切片。
- `EMBEDDING_DIM` 只校验响应向量维度，向量接口请求只包含 `model` 和 `input`。
- 只把命中切片放入用户消息；不把整个知识库、未命中材料或其他班级材料传给 LLM。
- 每条切片包含连续引用编号、材料标题、切片序号、字符区间和正文。

## 4. Skill 模型与执行

- Skill 文件采用课程第 5 课格式：空行前是中文元数据，空行后是说明正文。
- 必填字段为名称、适用条件和启用；可选字段为资料和工具。
- 保存 `source_text` 用于回看，解析后的字段分别入库。
- 候选集只包含当前应用绑定且启用的 Skill；按适用条件词法计分，零命中不选，同分取编号较小者，一次至多选择一个。
- 仅被选 Skill 的完整说明正文进入系统消息；元数据用于路由、检索过滤和工具候选集，不把 Skill 原文件无差别发送给 LLM。

## 5. LLM 请求与流式返回

- 使用 OpenAI 兼容的 `/chat/completions` 接口，模型地址、模型名和 API Key 只从环境变量读取。
- 系统消息按“提示词模板 → 被选 Skill → 固定输出约束”组装；检索切片和当前问题进入用户消息。
- 最近最多 6 条历史消息进入上下文，每条最多 500 字。
- 无 MCP 候选工具时直接发起流式请求；存在工具时先发起带 `tools` 的非流式决策请求，工具执行结束后再发起不带工具的流式最终回答请求。
- 浏览器接收 `meta`、`tool`、`delta`、`done`、`error` 五类 SSE 事件。

## 6. MCP 信任边界

- 同仓 `mcp-server/` 实现 `POST /mcp` 和 `GET /health`，支持 `initialize`、`tools/list`、`tools/call`。
- MCP Token 仅在 API 与 MCP Server 环境变量中出现；登记和查询接口只返回 `has_token`。
- 连接成功必须同时完成握手与工具发现；断开会清空发现清单。
- LLM 只看到当前 Skill 所需且已连接的工具声明。
- 模型返回的工具名必须属于候选集，参数按发现得到的 JSON Schema 校验后才能执行。
- 工具返回视为不可信数据：拒绝明显指令式内容并限制长度，再作为 `tool` 消息回传。
- 单次对话最多 2 个工具决策轮次、累计 4 次工具调用；超限后使用已有信息生成回答。

## 7. 验收轨迹与脱敏

- 每次消息保存一条 `llm_traces`，内容包括模板、消息、工具声明、模型返回、检索切片、Skill 路由和 MCP 事件。
- Authorization、API Key、MCP Token、Cookie 与数据库口令从不写入轨迹。
- 教师可以查看本班全部轨迹；学生只能查看自己触发的轨迹。
- 轨迹页面明确展示教师要求的五项验证结论，结论由实际保存的数据计算，而不是手写固定文案。

## 8. 失败语义

- 未登录返回 401；学生调用教师配置接口返回 403。
- 跨班应用、Skill、会话、MCP Server 与不存在资源统一返回 404。
- LLM 未配置或上游不可用时返回可读的 503；已开始 SSE 后用 `error` 事件结束。
- MCP 连接失败保持未连接；工具失败记录状态并允许 LLM 使用已有信息继续回答。
- Skill 文件字段缺失、重复、超长或引用未知工具时返回 400，且不产生数据库记录。
